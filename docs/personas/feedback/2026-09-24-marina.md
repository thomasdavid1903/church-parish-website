# Marina, news volunteer — 24 September 2026 (round 4)

This is the first hands-on run. It used the Playground **admin** account, because the seed still has no Editor account, so her real menu would be shorter. Laptop, desktop size.

**Verdict:** With difficulty. She can publish a Russian post and its English translation, and both appear in the right places. But the language defaults to English and the language box is hidden at the bottom of the sidebar. She could easily publish Russian text as an "English" post.

## Goals
| Goal | Result | Notes |
| --- | --- | --- |
| Log in, find where to write news | ⚠️ | Dashboard shows the WordPress welcome panel and a Polylang "Run the Setup Wizard" notice. Nothing says "News". The menu says **Posts** → **Add Post** |
| Russian announcement with photo, publish | ⚠️ | Published fine (photo upload not tested). **The new post defaults to English.** The Language box is the last panel in the sidebar, at 750px on a 768px screen. The pre-publish check doesn't show the language |
| Add English translation, link it | ✅ | The "+" next to the flag in Languages opens a linked English draft. The draft is **empty**, so she has to copy from the Russian tab |
| Both appear in the right language | ✅ | "Patronal feast, 21 September" is first on the English home page. «Престольный праздник 21 сентября» is first on /ru/novosti/. The switch links them. URL `/ru/prestolnyj-prazdnik-21-sentyabrya/` |
| Fix a typo in last week's post | Not tested | Posts list shows both languages with flags and edit icons, so this looks straightforward |

## What worked
- Russian slugs are transliterated automatically.
- Publish → "is now live" panel with **View Post**.
- News posts show the Russian date format on the site.

## Problems
1. **[Major] Wrong language by default.** She writes in Russian, and the post is saved as English unless she scrolls to the bottom of the sidebar and changes it. The post would then appear on the English site, and her English translation would have nowhere to go.
2. **[Minor] Wording.** The admin says "Posts" and the site says "News". The admin is in English (her profile could be set to Russian).
3. **[Minor] Dashboard noise.** The "Welcome to WordPress!" panel, Site Health, WordPress Events and the Polylang setup wizard notice all appear. Nothing points to "Write a news post".
4. **[Minor] Featured images don't show in lists.** The book post has a cover, but the News page and home news list show no thumbnails. She may wonder whether her photo "worked".
5. **[Minor] No default share image.** `og:image` is still empty on the home page and on posts without a photo.

## In their words
> «Опубликовала! Но я бы никогда не догадалась, что язык надо менять в самом низу справа.»

## Suggested fixes
- Default new posts to Russian for her. Polylang uses the admin's language filter: set the admin bar filter to Русский by default for Editors. Alternatively, move the Languages panel to the top of the sidebar, or add a notice when the title is Cyrillic and the language is English.
- Add a demo `editor` account to `tools/seed.php` (next to `headsister`, line 1323) so this can be tested as a real Editor.
- Add a Dashboard widget called "Write a news post (Написать новость)" and hide the welcome panel for Editors. Rename "Posts" to "News" in the admin menu.
- Default `og:image` to the hero photo (`functions.php:87`).
