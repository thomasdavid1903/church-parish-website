**New — Blocker (regression from round 2 fixes): search doesn't work in Russian.**
- On Russian pages the footer form submits to `/ru/glavnaya/?s=…`. WordPress then shows the front page's four latest news posts, with no "Результаты поиска" heading and no filtering.
- The form uses `home_url('/')`, which Polylang rewrites to the Russian static front page.
- Fix: use Polylang's search URL, `PLL()->links->get_home_url( $lang, true )` (i.e. `/ru/`). `/ru/?s=…` works correctly.
- File: `wp-content/themes/parish-cathedral/inc/header-footer.php`, footer search form.

**New — Minor:** Russian news posts have Cyrillic slugs. Shared links look like `/ru/%d0%b2%d0%be%d1%81…` in WhatsApp. Transliterate post slugs, as the page slugs already are (`voskresnaya-shkola`). A transliteration plugin such as *Cyr-To-Lat* would do this automatically for Marina's new posts.

> «Ссылку мужу переслала — английская версия открылась сразу. А поиск на русском ничего не нашёл.»
