1. **Major** No text alternative for the calendar. Add the regular-services list on `/services/` and an "Open the calendar in Google" link.
2. **Minor** No H1 on the home page. The first heading is H2 "Welcome", so the Cathedral name isn't announced as the page heading.
3. **Minor** The home page's H2/H3 order is odd: "Regular services", "Cathedral address" etc. are H3s that follow the "Latest news" H2, so they sound like part of the news.
4. **Minor** The footer repeats "Cathedral address", "Services" and "Support the Cathedral" as H2s. That's fine, but the page ends up with duplicate heading names.
5. Not checked: focus-ring visibility, colour contrast of the gold underline and muted italic subtitle, and 200% zoom. Do these on the next run.
