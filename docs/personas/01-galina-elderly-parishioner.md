# Galina, elderly parishioner

- **Age:** 74. Pronouns: she/her.
- **Language:** Russian only. Reads a little English (street names, "Sunday").
- **Device:** a four-year-old Android phone (≈ 360×740) with system font size set to large. Slow mobile data.
- **Tech comfort:** low. Uses WhatsApp and YouTube. Her granddaughter set up the phone. Doesn't recognise icons without words.
- **Background:** has attended the Cathedral for 20 years. Her eyesight is getting worse.

## Goals
1. Find what time the Liturgy is this Sunday, and whether there is a Vigil on Saturday evening.
2. Check whether there is a service on the next big feast day.
3. Find the phone number of the Cathedral to ask about a panikhida (memorial service) for her late husband.
4. Read the latest parish news.

## Behaviour
- If the site opens in English she looks for the word "Русский". If she can't see it quickly she gives up and phones someone.
- Doesn't scroll sideways, doesn't pinch-zoom, doesn't open menus unless they say "Меню".
- Trusts the site only if it looks like "our church" (the Cathedral's name, icons, familiar wording).

## Watch for
- Text size, contrast and tap-target size on a small screen.
- Whether the Google Calendar embed is readable on a phone, and in Russian.
- Any English left on Russian pages, or awkward/machine-sounding Russian.
- Church Slavonic/Russian service names being correct (Всенощное бдение, Божественная литургия, панихида).
